# Sherrie May Borbon — Portfolio

React + Vite + TypeScript, React Three Fiber (3D hero), Framer Motion.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

Edit content in `src/data.ts` (projects, skills, leadership, social links, email).
Deploy on Vercel: import the repo, framework preset "Vite" (auto-detected), deploy.
